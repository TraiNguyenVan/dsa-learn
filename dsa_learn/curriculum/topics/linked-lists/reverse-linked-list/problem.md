# Reverse Linked List

## Problem Description

Given the `head` of a singly linked list, reverse the list, and return the reversed list.

## Constraints

- The number of nodes in the list is in the range $[0, 5000]$.
- $-5000 \le \text{Node.val} \le 5000$

## Target Complexity

- **Time Complexity**: $O(N)$
- **Space Complexity**: $O(1)$ (iterative solution)

## Examples

### Example 1
```text
Input: head = [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]
```

### Example 2
```text
Input: head = [1, 2]
Output: [2, 1]
```

### Example 3
```text
Input: head = []
Output: []
```
